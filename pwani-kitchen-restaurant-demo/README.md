# Pwani Kitchen — Zanzibar Restaurant Concept

Live demo: https://pwani-kitchen-zanzibar-restaurant-concept-nf6twq.v2.appdeploy.ai/

A responsive, fictional restaurant website concept inspired by Zanzibar's coastal food culture. This is an unofficial portfolio demo, not an actual restaurant website.

## Features
- Responsive navigation and layout
- Sample menu with TZS pricing and working category filters
- Featured dishes and photo gallery
- Fictional story and location sections
- Contact and social details are deliberately left as placeholders
- Accessibility considerations, reduced-motion support, and graceful image fallbacks
- Clear unofficial-demo disclaimers

## Tech stack
- React, Vite, TypeScript
- Tailwind CSS
- Lucide React

## Run locally
```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
npm run preview
```

## Project notes
- Menu items/prices and content are illustrative. Replace them only with business-owner-approved information.
- Images are loaded from remote Unsplash URLs for this demo; verify licensing and use owner-approved or appropriately licensed assets before a client launch.
- No backend, database, order processing, payments, or enquiry submission is implemented.
- Contact details, WhatsApp, real map location, social accounts, opening hours, and actual business branding remain unconfigured.

## Before an official launch
- Obtain written permission to build and publish the official business website.
- Verify the business name, logo, menu, TZS prices, contact details, address, map and opening hours.
- Use only approved/licensed photos and brand assets.
- Agree on domain ownership, hosting, scope, payment, maintenance and handover.
- Test mobile and desktop layouts and all links after customisation.
